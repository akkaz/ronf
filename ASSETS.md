# Mascotte

`assets/mascotte-atlas.png` e uno sprite atlas con trasparenza generato con il tool integrato imagegen il 15/10/2026. Quattro colonne: sonno, risveglio, malumore, allarme. Tre righe: volpe, gatto, orso. La marmotta originale rimane in SVG nell'app. La posizione della riga dell'orso include un margine superiore aggiuntivo via CSS.

Prompt usato:

> Use case: stylized-concept. Asset type: ONE precisely aligned game sprite sheet for an Italian classroom sound-meter web app, transparent background. Create a professional polished 2D cartoon sprite atlas of exactly 12 separate full-body animal mascots arranged on a perfectly regular grid: 4 equal columns and 3 equal rows, no gaps between equal rectangular cells; canvas landscape 4:3, ideally 1536x1152. Each mascot fits fully inside its cell with 12% transparent padding; centered horizontally and feet at the same baseline. Row 1: a cute orange fox with fluffy tail and cream chest. Row 2: a cute gray-and-white cat with pointed ears and curved tail. Row 3: a friendly chocolate brown bear with tan muzzle and small round ears. All are sitting upright, same front-facing view and proportions within each row, friendly bold game illustration with confident smooth silhouettes, softly shaded color blocks and crisp high quality edges, expressive eyes, no outlines too thin. Columns left to right show the same character in four moods: (1) sound asleep, eyes closed, peaceful slight smile; (2) half awake, one eye open, ears attentive; (3) awake mildly grumpy, eyes open, eyebrows lowered; (4) startled awake, wide eyes and open mouth, raised arms. All four poses keep the animal identity and scale consistent. Actual alpha transparency everywhere outside characters, no white background, no checkered background, no floor, no scenery, no shadow reaching other cells, no props, no panels, no text, no letters, no labels, no watermarks. The grid will be cropped using CSS background-size 400% 300%, so strict equal-cell alignment is essential.
